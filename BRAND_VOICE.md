# Constancia — Brand Voice & Outbound Copy

Internal reference for anyone writing on behalf of Constancia: LinkedIn, sales decks, pitch emails, proposal cover letters. Keep this in sync with the homepage hero — if the site says it differently, the site wins.

---

## The one-liner

**Connected finance intelligence.**

Three words. Use it as the category line in any short-form context: bio strap, LinkedIn tagline, email signature, slide header.

## The longer version

> Constancia delivers connected finance intelligence. We bring disparate finance systems together — ERP, EPM, HRIS, CRM, data warehouse, the spreadsheets nobody talks about — into one source of truth, so CFOs decide on agreement instead of approximation.

Use this when a single paragraph is what's asked for (LinkedIn description, partner directory listing, conference programme bio).

---

## Voice rules

| Do | Don't |
|---|---|
| Speak in second person to one CFO. | Address "buyer personas" or "finance leaders worldwide". |
| Active verbs: **connect, translate, reconcile, see, decide**. | "Leverage", "robust", "holistic", "comprehensive", "best-in-class". |
| Name the systems. Oracle. SAP. NetSuite. Workday. HubSpot. Snowflake. | Vague "your tech stack" or "enterprise applications". |
| Outcome-led: "Start the close with confidence." | Feature-led: "Our consolidation workflow has 200+ pre-built rules." |
| Vary sentence length — short, then long, then medium. | Three sentences in a row that all run 18-22 words. |
| British English. | American spellings unless writing for a US audience. |
| Cite when you make a quantitative claim. | "Studies show", "research suggests", "industry experts agree". |
| Refer to the firm as "Constancia". | "1QG" (legacy). "We at Constancia" (verbose). |

## Words and phrases to **delete on sight**

These signal "AI-generated copy" or "stale consulting brand". If you spot them in draft work, cut.

- "leverage", "leveraged", "leveraging"
- "robust solution", "comprehensive approach", "holistic"
- "in today's fast-paced world", "in an ever-evolving landscape"
- "delve into", "dive into", "deep dive"
- "first and foremost", "needless to say", "it goes without saying"
- "synergy", "synergies", "synergistic"
- "thought leadership"
- "best-in-class", "world-class" (unless quoting a benchmark tier)
- "transformative", "transformational" — overused; prefer "this changes [specific thing]"
- "game-changer", "game-changing"
- "next-generation", "cutting-edge"
- "unleash the power of", "harness the power of"
- "in conclusion,", "in summary,"

## Sanity check

If you've written a paragraph for Constancia and you can swap "Constancia" for "any other consulting firm" without it losing meaning, **rewrite**. The voice has to feel like Constancia specifically — connected, direct, partner-not-vendor.
