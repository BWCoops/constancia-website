# Production build pipeline

The deploy/publish build does NOT use the default Vite + esbuild package.json
scripts. `package.json` build is `tsx script/build.ts`, a custom script that:
- `vite build` → client into `dist/public`
- `esbuild` bundles `server/index.ts` → `dist/index.cjs` (CJS, minified),
  bundling only an allowlist of server deps and marking everything else external
- `start` runs `node dist/index.cjs`

**Why this matters:** `script/build.ts` has gone missing from the working
branch before, causing publish to fail with
`ERR_MODULE_NOT_FOUND ... script/build.ts`. The file is not regenerated by
anything — if it disappears, restore it from git history
(`git log --all -- script/build.ts`) rather than rewriting package.json
(package.json must not be edited).

**How to apply:** If a publish fails with a missing build module, check
`script/build.ts` exists first. When adding a new ESM-only server dependency
that must be bundled (CJS/ESM interop errors at runtime), add it to the
`allowlist` array in that file.
